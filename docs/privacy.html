Rogue Shard Bot: Privacy Policy

Rogue Shard Bot is a small tool run by the author of the Rogue Shard mod on their own computer. It packs development builds of the mod, uploads them to the author's own Google Drive and posts the download link to the mod's Discord server.

  • It asks only for the drive.file permission: it can see and change only the files it created itself, nothing else on the Drive.
  • Those files are mod builds, shared by link so that testers can download them. The previous build is removed when a new one is posted.
  • It does not collect, store or share any personal data of anyone, and it is not used by anyone except the mod's author.

Questions: the Rogue Shard mod page on Nexus Mods or its Discord server.
